메인 혼자 할 때 vs 전부 나눠 맡길 때

무엇을 비교했나: "메인 혼자"는 메인 AI가 하위 AI 없이 직접 구현한 경우다. 세 도구 모두 기록상 하위 AI를 쓰지 않았다(CUELO 대규모 6종 과제는 위임을 시도했으나 당시 설정 오류로 하위 AI 후보를 받지 못해 혼자 했다). "전부 위임"은 직접 고치지 말고 하위 AI(Maker·서브에이전트)에게 맡기라고 강제한 경우다. 비교 칩은 같은 도구의 메인 혼자 결과 대비다. 하위 AI 모델이 다르면 토큰 단가가 수십 배 다르므로 "AI 사용량"이 아니라 "API 환산 요금"으로 비교한다. Codex는 하위 AI의 사용량이 기록에 따로 나오지 않아 사용량·요금이 실제보다 적게 잡혔을 수 있다. Claude Code는 실행 기록에 중간 도구 호출이 남지 않아 실제 위임 여부를 확인하지 못했다. Codex 보통 과제 위임 2회는 하위 AI 생성 오류(도구 자체 문제)로 코드를 전혀 고치지 못해 표에서 뺐다.

용어 풀이

AI 사용량
AI가 읽고 쓴 글자 양(토큰)을 요금 비중으로 환산한 값이다. 새로 읽은 양 + 0.1×이미 기억해 둔 부분 다시 읽기 + 1.25×기억해 두기 + 8×AI가 쓴 양. 비율은 가정값이고 모든 모델에 같게 적용한다. 같은 모델끼리는 적을수록 싸지만, 모델이 다르면 토큰 단가가 수십 배 달라 이 값으로 돈을 비교할 수 없다(아래 API 환산 요금을 본다). 위임한 경우 하위 AI가 쓴 양도 합친다.
맞힌 테스트 (예: 958/960)
AI가 만든 프로그램을 검사하는 자동 채점 문항 수다. 문항 하나는 "이 입력을 넣으면 이 답이 나와야 한다" 같은 확인 한 가지다. 예를 들어 초대형 과제에는 문항이 960개 있고, 958/960은 960개 중 958개를 통과했다는 뜻이다. 문항은 AI가 작업 중에 볼 수 없게 숨겨 두었다가 끝난 뒤에만 돌렸다. 시험지를 미리 보지 못하게 한 채점이다.
정답 횟수
같은 과제를 여러 번(기본 3회, 위임·대규모는 2회) 돌려 채점 테스트를 모두 통과한 횟수.
Maker·서브에이전트
메인 AI가 일을 나눠 맡기는 하위 AI.
high / medium
AI에게 생각을 얼마나 깊게 시키는지 설정. high가 더 깊고 느리다.
API 환산 요금
기록된 토큰을 각 회사 공식 API 단가(1M 토큰당 표준 요금)로 곱한 값이다. 측정은 월정액 구독으로 돌렸으므로 실제 청구액이 아니라 "API로 냈다면 얼마인가"다. 모델마다 따로 계산해 합친다. 단가 출처(2026-09-25 확인): Anthropic Opus 5.5(입력 $4 · 출력 $20 · 캐시 읽기 $0.20), OpenAI 가격표(GPT-6 Luna 입력 $0.10 · 출력 $0.50, Daybreak Blue = gpt-5.6-sol 입력 $4 · 출력 $20), DeepSeek 가격표(V4.1 Flash 입력 $0.15 · 출력 $0.60, 혼잡 시간 2배). Claude Code는 도구가 직접 남긴 요금을 쓴다. Codex는 요청별 기록이 없어 긴 문맥 할증을 넣지 못했고 하위 AI 몫이 빠질 수 있어 실제보다 낮을 수 있다.

자세히 보기 (측정 방법)

순위는 정답률 → 시간 → 사용량 순이다. 돈 비교는 API 환산 요금 열을 본다. 그래프의 가는 선은 최소~최대 범위다. CUELO 시간은 세션 유휴 대기를 뺀 실제 작업 시간이다. 과제 폴더의 규칙 파일은 모든 도구에서 숨겨 같은 조건을 맞췄다. 총 76회 실행.
